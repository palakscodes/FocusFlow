# FocusFlow

A student productivity dashboard designed to help students organize tasks, prioritize their work, track progress, and maintain focused study sessions.

## Features

- Add and manage tasks
- Set task priority: High, Medium, or Low
- Organize tasks by category
- Add due dates
- Mark tasks as completed
- Delete tasks
- Track total, completed, and pending tasks
- Visual progress tracking
- Smart Priority Recommendation
- Custom focus timer
- Tasks saved using browser localStorage

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run npm install
5. Run npm run dev

## Purpose

FocusFlow is a student productivity tool for managing academic and personal tasks while encouraging focused work through a built-in timer and progress tracking.
